# Deep Colony

Колония-выживание в разрезе астероида: визуальный стиль и физика — из Oxygen Not Included,
модель колонистов (черты, навыки, настроение, срывы) — из RimWorld.

Запуск: открыть `index.html` в браузере (нужен http-сервер из-за ES-модулей):

```bash
python3 -m http.server 8000   # затем http://localhost:8000
```

## Что уже есть
- **Физика флюидов**: давление газа, разделение по молярной массе (H₂ всплывает, CO₂ оседает),
  жидкости со сжатием столба и перетоком, вытеснение газа водой, перенос тепла вместе с массой.
- **Фазовые переходы**: лёд ↔ вода ↔ пар со скрытой теплотой, кипение, испарение, конденсация.
- **Тепло**: теплоёмкость по среде, проводимость, нагрев от оборудования, перегрев/обморожение дупликантов.
- **Гейзеры**: паровые, водяные, CO₂ и водородные жерла с периодами активности.
- **Колонисты**: кислород, еда, сон, стресс, здоровье, настроение с факторами, нервные срывы,
  случайные черты характера, рост навыков от работы.
- **Работы**: копка, стройка, подвоз материалов, переноска на склады, урожай, ручной генератор.
- **Энергия**: генераторы, батареи, потребители с приоритетом питания.
- **Мир**: биомы (грунт, песчаник, гранит, уголь, медь, слизь, лёд), пещеры, подземные озёра, свет и тьма.

## Управление
- ЛКМ — применить инструмент (можно протягивать область), ПКМ/Esc — сброс инструмента
- Shift+перетаскивание или СКМ — камера, колесо — зум, WASD/стрелки — прокрутка
- Space — пауза, 1/2/3 — скорость
- Панель слева — наложения: газы, тепло, энергия
